# UI 设计规则(设计语言「心跳」)

日期:2026-09-15
状态:**v1.2(2026-09-19 增补附录 B:消息/聊天页落地补充),设计内容已获用户批准**(浏览器视觉评审通过);本文件是**常驻规则文档**
性质:以后所有 App 端 UI 开发(改版/新页面/新组件/新动效)一律以本文件为准。与历史视觉专项文档(微信式聊天、抖音式消息页、微博式广场)冲突的部分,**旧文档作废,以本文件为准**。
背景:用户提出「App 端 UI 不美观、单调、布局丑陋、无动效、图标单色,不能作为商业产品面向大众」。逐轮澄清定下四个基准(见 §11 决策记录):风格=年轻潮流派;主色=保留品牌粉 #FF2C55 做锚点 + 辅助色/渐变体系;字体=混排(中文系统 + 拉丁 Space Grotesk);整改顺序=先主界面后低频页。**本轮只定规则,页面改造另行立项。**
上游:原始 spec `2026-09-09-dating-app-mvp-design.md`;被本文件取代的视觉决策:`2026-09-12-chat-profile-wechat-design.md`(微信式版式)、`2026-09-11-ban-notice-message-page-design.md`(抖音式消息页)、`2026-09-12-square-feed-design.md`(微博式信息流)中与本文冲突的部分。

## 1. 设计定位与原则

**一句话:年轻、有心动感、干净有层次。** 气质关键词:活力、亲近、轻盈、自信。

三条铁律:

1. **一屏一个高音** —— 粉色与渐变只出现在引导视线的位置(主按钮、选中态、未读角标、配对时刻、在线光);其余一切走中性色阶。**「不单调」靠让颜色出现在该出现的位置,不靠到处加颜色。**
2. **动效服务反馈与情感,不做装饰** —— 每次动效要么回答「我的操作生效了吗」,要么放大一个情感时刻;两者之外不动。
3. **一切走 token,禁止就地硬编码** —— 新代码不允许出现裸 hex、裸字号、裸间距、裸圆角;先从 token 取值,查无可用值时按 §9 流程扩展。

**非目标(v1)**:深色模式(留给 v2,不做双主题预埋);第三方 UI kit;纯装饰动画;更换品牌粉。

| `green` | `#12C48B` | 在线点、成功态 |
| `amber` | `#FFB020` | 星标、会员、精选、成就 |
| `text1` | `#16181D` | 主文字、标题 |
| `text2` | `#8A8F9E` | 次级文字、预览、说明 |
| `text3` | `#B3B7C0` | 三级文字、时间戳、禁用文字 |
| `divider` | `#EEF0F4` | 分割线、输入框描边、骨架屏底色 |
| `bgPage` | `#F6F7FB` | 页面底色(冷调浅灰) |

| `warning` | `#FFB020` | 同 `amber` |

### 2.2 使用规则

- 一屏内 **`gradientHeart` 出现不超过 2 处**(通常是「一个主按钮 + 一处状态强调」);`brand` 纯色可多次用于小元素(角标、点赞)。
- 文字不用渐变、不用彩色(链接/强调按钮除外);正文永远 `text1`,次级信息 `text2`,时间戳 `text3`。
- 头像底色允许低饱和柔色(如 `#FFE3D6`/`#DCE7FF`),文字取同系深色——不占「高音」额度。
- 品牌粉的色相(#FF2C55)不可改;渐变终点的橙位(#FF7A45)可微调,需走 §9。

### 2.3 旧值迁移对照(页面改造时照此替换)

| 旧值 | 出现位置 | 新 token |
|---|---|---|
| `ThemeData(colorSchemeSeed: Colors.pink)` | `app.dart` | colorScheme 从 `brand` 派生(见 §8) |
| `#FF2C55` 硬编码 ×4 | home_shell 角标 / chats_page / message_bubble / post_card | `brand` / `gradientHeart` |
| `#F7F3F5` 页面底 ×7+ | square/my_posts/post_detail/两个 profile/emoji_panel/more_panel | `bgPage` |
| `#8A8F98` `#9AA0A8` | chat 系列 | `text2` / `text3` |
| `#999999` `#888888` `#666666` | profile / square 系列 | `text3` / `text2` / `text1` |

## 3. 字体与排版

### 3.1 策略(混排)

- **中文**:系统字体自动适配(iOS PingFang SC / 小米 MiSans / 华为 HarmonyOS Sans / 其他 Noto Sans CJK)。
- **拉丁与数字**:打包 **Space Grotesk**(SIL OFL 1.1,免费商用;需随包放 OFL 许可文件),权重 400 / 500 / 700,共约 100KB。
- 落地方式:全局 `fontFamily: 'SpaceGrotesk'` + `fontFamilyFallback: ['PingFang SC', 'MiSans', 'HarmonyOS Sans', 'sans-serif']` —— 拉丁/数字自动用 SG,中文自动落系统(Flutter 按字形 fallback)。

### 3.2 字阶

| 名称 | 字号/字重 | 字距 | 用途 |
|---|---|---|---|
| `display` | 28–34 / w800 | -0.02em | Tab 主页大标题、年龄大字、金额数字 |
| `title` | 20 / w700 | -0.01em | 区块标题、弹层标题 |
| `subtitle` | 16 / w600 | 0 | 列表主文字(昵称、会话名) |
| `body` | 15 / w400–500 | 0 | 正文、消息文本、按钮文字(按钮用 w600–700) |
| `caption` | 13 / w400 | 0 | 辅助说明、预览文字 |
| `micro` | 11–12 / w400–700 | 0 | 角标、标签、底栏文字(角标 w700) |

### 3.3 规则

- 计数/年龄/距离等数字用 Space Grotesk 的 w700;行高统一按 1.2(标题)/1.45(正文)。
- 最小字号 11(角标专用);正文不得小于 13。
- 中文大标题走 w800;若某系统字体无 w800 字重,退回其最粗可用字重,不做假粗体。

## 4. 图标

- **一律使用 Material `*_rounded` 圆角变体**(Flutter 自带字体,零新增依赖);禁用默认直角变体。
- 尺寸档:16(行内)/ 20(按钮内)/ 22(底栏未选中)/ 24(导航、工具栏)。
- 状态:
  - 未选中:描边样式,`text2` 或 `text3`;
  - 选中:填充样式 + `gradientHeart` 着色(用 ShaderMask 封装为 `GradientIcon` 组件);底栏选中态用「渐变胶囊 + 白图标」而非着色(见 §7 底栏)。
- 语义色分配(全 App 统一):在线=`green` 呼吸点;系统/官方=`violet`;未读=`gradientHeart` 角标;点赞=`brand`;星标/会员=`amber`;错误=`danger`。
- 空态与插图:**不得使用灰色图标占位**;用大号彩色元素(渐变几何图形或 emoji),见 §7 空态。

## 5. 形状与布局

### 5.1 基础值

- **圆角**:大卡/大图 20;输入框/次级容器 16;小标签 8;按钮、chip、角标 全圆;底部弹层上圆角 24;发现卡(全屏大卡)24。
- **间距**:全部 4 的倍数 —— 4 / 8 / 12 / 16 / 20 / 24;页面水平内边距 16;卡片之间 12;区块之间 24。
- **阴影**:浮卡 `0 6px 18px rgba(22,24,29,.06)`;悬浮底栏 `0 10px 24px rgba(22,24,29,.10)`;主按钮 `0 10px 24px rgba(255,44,85,.35)`。阴影只用于分层,不用于装饰;同屏阴影层级不超过 2 种。

### 5.2 页面骨架

- **Tab 主页**(发现/广场/消息/我的):底色 `bgPage`;顶部大标题(`display` 字阶、左对齐、上下留白 16/12);内容区滚动;**悬浮胶囊底栏**(见 §7)。
- **二级页**:顶栏高 52(返回箭头 22 `text1` + 标题 `17/w600` 居中);内容按卡片组织。
- **列表行**:高 64–72;头像 44–48;标题 `subtitle`;预览 `caption`。

### 5.3 头像规范(全 App 统一)

- **一律圆形**(废除微信式方头像):尺寸档 28 / 32 / 40 / 48 / 56 / 96。
- **光晕环**:渐变描边 2.5px(`gradientHeart`),含义 = 「可聊/新配对」;普通关系无环。
- **在线点**:直径 11(小场景 8),`green` + 呼吸光晕,描边颜色 = 所在背景色(白卡上白描边)。
- 相册/照片网格不是头像:图片圆角 12,全屏大图 20。

## 6. 动效

### 6.1 时长与曲线

| 档 | 时长 | 曲线 | 用途 |
|---|---|---|---|
| `fast` | 150ms | easeOutCubic | 按压反馈、开关 |
| `base` | 220ms | easeOutCubic | 淡入、图标弹跳、角标出现 |
| `medium` | 320ms | easeOutCubic | 列表项入场、展开/收起、页面 push |
| `hero` | 380ms | easeOutCubic | 共享元素转场 |
| `cinematic` | 900–1400ms | easeOutBack(回弹 ≤1.1)+ 编排 | 情感时刻(配对) |
| 循环 | 1.2–2.4s | sine ease-in-out | 呼吸类氛围(在线点、骨架屏) |

### 6.2 三档清单

1. **微交互**(每个可点区域必须有):按钮按压 `scale .96`(fast);点赞心跳脉冲 1→1.25→1(base,配 `brand` 变色);底栏切换选中弹跳(base)+ 胶囊位移动画(medium);角标出现 `scale .6→1.1→1`(base)。
2. **结构动效**:列表入场「上移 12px + 淡入」、逐项错峰 40ms(medium);页面 push 右滑入;Hero 转场两处 —— 头像→他人资料页、动态卡→动态详情。
3. **情感时刻**(贵重所以稀有):配对成功全屏编排 —— 光晕从双头像扩散、双头像相向碰撞、粒子飘散(cinematic,可点击跳过);仅配对成功触发,其他一律不用。

### 6.3 约束

- 尊重系统「减弱动态效果」:`MediaQuery.disableAnimations` 为真时,全部降级为 200ms 淡入或直接切换。
- 动效不得阻塞交互;超过 400ms 的动画必须可跳过。

## 8. Flutter 落地

(页面改造另行立项;本节规定底座怎么搭,保证改造时有据可依。)

**新增 `app/lib/core/theme/`**,一个 token 一个文件:

| 文件 | 内容 |
|---|---|
| `app_colors.dart` | §2 全部色值常量(`AppColors.brand` 等) |
| `app_gradients.dart` | `gradientHeart` / `gradientSystem` |
| `app_typography.dart` | §3 字阶 → `TextTheme` + 命名样式(`AppText.display` 等) |
| `app_spacing.dart` / `app_radius.dart` | §5 间距与圆角常量 |
| `app_motion.dart` | §6 时长/曲线常量 |
| `app_shadows.dart` | §5 阴影预设 |
| `app_theme.dart` | 组装 `ThemeData`:colorScheme 从 `brand` 派生、textTheme、组件主题(NavigationBar→自绘底栏、输入框、SnackBar 等)、字体 |

- 页面取用:`AppColors.xxx` 常量类直取(新手友好、无样板);Material 组件经 `ThemeData` 自动继承。
- 通用组件 `app/lib/core/widgets/`(新增):`AppButton`、`AppAvatar`(光晕环/在线点内置)、`AppBadge`、`AppCard`、`GradientIcon`、`AppSkeleton`、`AppEmptyState`、`AppToast`。
- 字体资源:`app/assets/fonts/SpaceGrotesk-{Regular,Medium,Bold}.ttf` + `OFL.txt`;`pubspec.yaml` 声明 `family: SpaceGrotesk`。
- **迁移纪律**:逐页改造只动视觉层,不改行为与测试断言语义;每页完成后 `flutter analyze` 零告警 + 该页既有测试全绿 + 模拟器手测;顺手清掉该页裸硬编码(照 §2.3 对照表)。
- **实施顺序**(另行立项):① 底座(tokens/theme/widgets)+ 底栏 shell → ② 发现页 → ③ 消息页 + 聊天页 → ④ 我的 + 资料页 → ⑤ 广场 → ⑥ 二级页(登录/引导/设置/编辑等)。每批完成后用户模拟器验收。

## 9. 规则边界

- 唯一允许偏离的情形:本文件未覆盖的新场景。处理顺序:先挑最接近的 token 复用 → 实现时注明;确实需要新 token 时,**先更新本文件(v1.x + 变更记录)再写代码**。
- 禁止:新代码出现裸 hex/裸字号/裸间距/裸圆角;引入 §2 之外的色相;纯装饰动画;用灰色图标做空态。

## 10. 未决与后续

- 深色模式:v1 不做;若做,本文件升 v2 并补一套 token 映射。
- 定制插画:空态先用 emoji/渐变几何;若后续要专属插画形象,另立设计任务。
- 视觉回归(golden 测试):可选引入,用于防「改 A 页碰坏 B 页」。
- 页面级布局的最终形态在逐页改造时定,但不得违反本文件;逐页产出可作为本文件的附录补充。

## 附录 A:发现页落地补充(2026-09-19,批次②)

本附录是 §9 边界流程的产出:以下场景规则正文未覆盖,经浏览器模拟图评审确认后定稿;后续页面遇同类场景以此为准。

### A.1 滑卡操作钮(发现页专属)

- 跳过:圆形 56,白底 + 1.5px `divider` 描边,`close_rounded` 24 `text3`,浮卡阴影
- 喜欢:圆形 64,`gradientHeart` 底,`favorite_rounded` 24 白,主按钮光晕阴影
- 间距 44;按压 scale .96(`fast`);点喜欢时脉冲 `1→1.25→1`(`base`,与滑卡飞出并行,不阻塞)
- 语义:两钮等价于左右滑卡(与拖拽同一套判定)

### A.2 照片叠字 scrim

- 渐变:上 `Colors.transparent` → 下 `AppColors.photoScrim`(`#101114`,87%)
- 用途:照片上叠文字时的对比度兜底;叠字用白色系(主 93%、次 72%、辅 88%)

### A.3 涟漪空态元素(HeartRipple)

- 中心渐变光点(**固定 14px,不随尺寸缩放**;带 brand 光晕)+ **双波循环扩散环**(自光点处诞生、扩大渐隐,**不留静态底环**);尺寸 **180**(手测观感上调,§7 大号元素 72–96 之例外,以本附录为准)
- 波纹:双波错峰(相位 0/0.5),自 0.2 倍尺寸扩散至 1.0 倍、不透明度 .65→0,2.4s 循环;「减弱动态效果」时仅剩光点
- 语义:与「心跳光晕」签名同源,「心跳在找、暂时没有回音」;空态大号元素以此为默认,emoji 为备选(AppEmptyState 的 `mark` 参数优先)
- 无限动画纪律:可见状态的测试只用有限 `pump`(见 `docs/pitfalls/testing.md`)

### A.4 照片切换指示(胶囊点)
