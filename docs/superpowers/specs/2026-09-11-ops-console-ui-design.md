# 运营审核台 UI 改版设计(宝塔式亮色)

日期:2026-09-11
状态:已与用户逐节确认,待用户终审
上游:spec `2026-09-11-moderation-console-design.md`(本设计替代其 §2 中的样式选型:Pico.css → 自写 CSS)
背景:用户验收 `/ops/` 首版后认为页面布局不够好,要求改成宝塔面板式布局(左侧边栏 + 顶栏 + 内容区)、亮色配色,主色蓝。

## 1. 目标与范围

把 `ops` 审核台全部页面(含登录页)从「Pico 默认观感 + 水平导航」改成宝塔面板式三区布局 + 亮色主题。**只改视觉与结构,不改任何行为**:路由、视图、HTMX 交互、页面文案一字不动(test 断言全部保持绿)。

**非目标(YAGNI):** 深色模式、主题切换、移动端适配(桌面优先,同原 spec)、侧边栏折叠。

## 2. 布局结构

```
┌────────────┬────────────────────────────────┐
│ 运营审核台  │  举报队列           139…  退出  │ ← 顶栏(56px):当前页标题 + 用户/退出
│(品牌区)     ├────────────────────────────────┤
│ ▸ 举报  ③  │  ┌──────────────────────────┐  │
│ ▸ 照片审核 ②│  │ 卡片(白底/8px 圆角/细边框) │  │
│ ▸ 用户      │  │ 表格 / 表单 / 照片审核行    │  │
│ ▸ 日志      │  └──────────────────────────┘  │
└────────────┴────────────────────────────────┘
 侧边栏 220px        内容区(浅灰底)
```

- **侧边栏(220px,固定)**:白底 + 右侧 1px 分隔线;顶部品牌区「运营审核台」;菜单项高 40px,字号 14px,每项带 16px 内联 SVG 图标(flag/图片/用户/清单,零依赖);hover 浅灰蓝底;选中态 = 浅蓝底(`#e8f0fe`)+ 蓝字 + 左侧 3px 蓝条;待办角标(红底白字胶囊,min-width 18px)靠右
- **顶栏(56px)**:白底 + 底部分隔线;左侧当前页标题(各页用模板 block 提供);右侧用户名 + 退出按钮;退出仍为 POST 表单
- **内容区**:浅灰底,内边距 20px;内容块一律「白卡片」:白底、8px 圆角、1px 边框 `#e8eaed`、极浅阴影

## 3. 配色(亮色,主色蓝)

| 用途 | 值 |
|---|---|
| 主色(按钮/选中/链接) | `#2c7be5`,hover/active 深一档 `#1a68d1` |
| 页面底色 | `#f5f6f8` |
| 卡片/侧边栏/顶栏底色 | `#ffffff` |
| 分隔线/边框 | `#e8eaed` |
| 正文 | `#2b2f36`;次要文字 `#6b7280` |
| 语义色 | 通过/已处理/解封 = 绿 `#1e9e57`;驳回/重度封禁 = 红 `#d93025`;轻度封禁 = 橙 `#e8890c`;待办角标 = 红 `#d93025` |

## 4. 组件规范

- **按钮**:紧凑小尺寸(高 28-32px,内边距 10-14px);主操作蓝底白字;次要白底灰边;危险操作(驳回、重度封禁)红;圆角 4px;`disabled` 降透明度
- **表格**:宽度 100%;表头浅灰底(`#fafbfc`)+ 13px;行底部 1px 分隔线;行 hover 浅蓝(`#f5f9ff`);单元格内边距 8-12px
- **表单控件**:input/select 高 32px、4px 圆角、1px 边框,聚焦时蓝边框 + 2px 淡蓝光晕;label 13px
- **状态胶囊**:`get_status_display` 类文字套彩色胶囊标签 —— 待处理=橙、已处理=绿、未完善=灰、已完善=绿、轻度封禁=橙、重度封禁=红
- **筛选 tab**:小标签样式,选中 = 蓝字 + 2px 蓝色下划线(替代当前粗体+下划线)
- **照片审核行**:保持现结构(勾选框 + 大图 + 信息列 + 操作表单),图片 6px 圆角 + 细边框;勾选框 accent-color 蓝
- **登录页**:独立全屏(不套侧边栏壳),浅灰底 + 居中白卡片(约 380px 宽、圆角阴影),标题 + 表单

## 5. 实现范围

- **`ops/templates/ops/base.html` 重构**为三区壳(sidebar + topbar + content),新增 `{% block page_title %}`;各页模板把 `<h2>` 标题文案移入 `page_title` block 并**删掉正文里的 h2**(避免标题重复;文案一字不改,测试断言不破)
- **`ops/templates/ops/login.html`** 脱离 base.html,独立成页(自带 `<!doctype>`),复用同一 ops.css
- **`ops/static/ops/ops.css` 整体重写**(约 250 行,替代现 ~40 行);**删除** `ops/static/ops/vendor/pico.min.css` 及 base 中的 `<link>`
- HTMX 属性、表单结构、CSRF、视图逻辑**零改动**;htmx.min.js 保留

- 后端全量测试保持全绿(180 个;文案未动,断言不受影响)
- **视觉验证**:Playwright 截图登录页与四个功能页(举报列表/详情、照片审核、用户详情、日志)。为截图临时创建一个 is_staff 账号,截图后删除;不动用户现有 admin 账号
