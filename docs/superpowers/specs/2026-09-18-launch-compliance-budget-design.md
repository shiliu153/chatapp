日期:2026-09-18 · 状态:设计已获用户认可(对话确认:路线 A 双轨并行 / 标准预算档 / 安卓 + iOS 同步 / 目标 3~4 个月上架)
关联:`2026-09-18-m4-deploy-runthrough-design.md`(服务器跑通,已完成实为前序)、执行计划 `../plans/2026-09-18-launch-execution.md`(流程表以此为准)、`../../deploy-runbook.md`(运维与上线待办)

## 1. 背景与决策

**现状**:后端已上线跑通(阿里云轻量 2C2G,IP:80 测试,`<SERVER_IP>`);无经营主体(打算注册);有会员付费计划;目标:国内安卓五大商店 + 中国区 App Store,预算标准档(2~5 万/年量级),期望 3~4 个月上架。

**决策(方案 A:双轨并行)**:

1. **上架轨(免费版)**:公司注册 → 资质链条(软著/ICP 备案/App 备案/公安备案/安全评估报告)→ 商店提审上架,**只带免费功能**,目标第 3~4 个月。
2. **付费轨(ICP 证)**:ICP 经营许可证的硬时钟(3 人社保连缴 1~3 个月 + 审批 40~60 工作日)从**公司注册当月就启动**,预计第 5~7 个月取证;**取证前付费功能一律不上线**。
3. 技术侧配套(域名/HTTPS/短信/内容安全/COS/备份/隐私政策页等)与商务资质并行推进。

**为什么是 A(而非等证齐全的 B、或彻底延后办证的 C)**:ICP 证的社保时钟是硬瓶颈,越早启动越好;免费版上架恰好不需要 ICP 证(涉付费才触发),两条线并行不浪费一天。B 会晚 3~4 个月见用户;C 把付费无限期延后,若产品起量会长期无收入。

**关键约束(法律红线)**:未取得 ICP 经营许可证前,任何会员/增值收费都属违法经营(罚款 10 万~100 万元或违法所得 3~5 倍)。不存在"先收费边办证"的过渡方案。

## 3. 预算表

**口径说明**:三档**均为方案 A**(都含 ICP 证链条,差异只在执行方式:自办/代办、自建/云服务、是否含等保);金额单位人民币;"经济档" = 尽量自办/自建;"标准档" = 关键环节买省心(推荐);"无忧档" = 加冗余。活动价随时变动,下单前以官网实时报价为准。**不含**:收入相关费率(0.6% / IAP 25%)、人员工资。

### 3.1 三档总览(第一年)

| 档位 | 第一年合计(估) | 主要差异 |
|---|---|---|
| 经济档 | **约 3.0~4.1 万** | 资质自办、MySQL/Redis 自建、暂缓等保、现有 2C2G 暂不升配 |

## 4. 资质申请指南(9 项,每项:要求 → 材料 → 流程 → 时间 → 费用)

### 4.1 公司注册(有限责任公司)

- **要求**:注册资本 ≥100 万(认缴制,新公司法要求 5 年内实缴);经营范围**必须含**:婚姻介绍服务、互联网信息服务(第二类增值电信业务,ICP 证必备)、软件开发/信息技术服务
- **材料**:法人/股东身份证、注册地址证明、公司章程、公司名称
- **流程**:核名 → 设立登记(多地一网通办)→ 刻章 → 银行对公开户(需预约)→ 税务报到
- **时间**:3~10 工作日(对公户另需 1~2 周)
- **费用**:自办 0 + 刻章 200~500;代办 800~3000
- **坑**:①经营范围漏"第二类增值电信业务"会在 ICP 证阶段返工;②对公户开立慢,影响后续支付商户;③注册地决定备案管局与社保口径,先想好落在哪个城市

### 4.2 ICP 备案(网站备案,非经营)

- **要求**:企业主体;域名已实名且主体一致;服务器在**大陆**且购买时长满足服务商要求(阿里云≥3 个月)
- **材料**:营业执照、法人身份证、域名证书、备案核验单、人脸核验
- **流程**:服务商备案系统提交 → 服务商初审(1~2 天)→ 管局短信核验 → 管局审核
- **时间**:2~4 周
- **费用**:免费
- **坑**:备案期间该域名**不得开放网站访问**(需保持"未建成"状态),我们的服务器已就绪,切域名要等备案通过;备案信息(主体/法人)变更须及时同步,与 App 备案强绑定

### 4.3 App 备案(工信部)

- **要求**:主体已有 ICP 备案;App 名称、软著名称、商店上架名称**三者一字不差**
- **材料**:包名/Bundle ID、签名公钥与 MD5、隐私政策、SDK 清单、图标
- **流程**:通过接入商(阿里云/腾讯云)系统提交 → 管局审核(法定 20 工作日)
- **时间**:1~3 周
- **费用**:免费
- **坑**:常见驳回 = 主体/域名不一致、隐私政策列出的 SDK 与实际不符、包名/签名不匹配;安卓与 iOS 同名只备一次(备案号带 -A)

### 4.4 公安联网备案

- **要求**:ICP 备案通过后 **30 日内**完成
- **材料**:营业执照、法人身份证、ICP 备案号、域名证书
- **流程**:全国互联网安全管理服务平台(beian.mps.gov.cn)在线提交
- **时间**:3~5 天
- **费用**:免费

### 4.5 软件著作权登记

- **要求**:安卓各大商店基本必交(小米 FAQ 明文"所有应用上架均需要";华为口径有冲突,见 §6)
- **材料**:源码前后各 30 页(共 60 页)、软件说明书、申请表
- **流程**:中国版权保护中心线上提交
- **时间**:普通 30~60 工作日;加急 3~10 工作日
- **费用**:官方 0(2017 年起停征);代办 500~1500,加急另 800~2000
- **坑**:软著名称必须 = 未来 App 上架名,中途改名要重新登记;建议与公司注册同步启动

### 4.6 ICP 经营许可证(增值电信业务经营许可证 · 信息服务业务 B25)

- **要求**:内资公司;注册资本 ≥100 万;3 名员工社保**连缴 1~3 个月**(省际差异);经营范围含"第二类增值电信业务"
- **材料**:营业执照、公司章程、社保缴纳记录、域名证书、业务发展方案、技术方案、等保材料(部分省要求,见 §6)
- **流程**:省通信管理局线上申报 → 受理 → 审查 → 发证
- **时间**:受理后 40~60 工作日;**从公司注册算起实际 5~7 个月**(社保时钟 + 审批)
- **费用**:官方 0;代办 5000~15000
- **坑(最关键)**:**无合法过渡**——未取证先收费即违法;付费功能开关必须等技术侧拿到证后手动开启;社保人数与月数是硬条件,提前规划 3 人

### 4.7 算法备案(互联网信息服务算法推荐)

- **要求**:提供算法推荐服务(婚恋匹配属需备案场景)
- **材料**:算法自评估报告(80~120 页)、算法说明书、安全管理制度
- **流程**:互联网信息服务算法备案系统(beian.cac.gov.cn)
- **时间**:2~4 个月
- **费用**:官方免费
- **坑**:报告工作量大,建议与 ICP 证并行推进;上线前完成首次备案(免费版含推荐流,不宜拖太久)

### 4.8 网络安全等级保护(等保)

- **要求**:二级起步(社交类是否有三级要求无统一口径,须向属地确认)
- **流程**:定级 → 公安备案 → 整改 → 第三方测评 → 每 2 年复测
- **时间**:30~45 天
- **费用**:二级测评 2~4 万;含整改 3~6 万
- **状态**:强制性与被要求时机**待确认**(见 §6),标准档先不列入,作为风险准备金

### 4.9 安全评估报告(商店必交,免费自评)

- **要求**:具有舆论属性或社会动员能力的互联网信息服务(交友类是典型);华为/小米/vivo 明列交友类必交
- **材料**:自评估报告(主体信息、服务内容、安全管理制度、技术措施、个人信息保护等)
- **流程**:全国互联网安全管理服务平台提交 → 取得"通过"结果截图 → 作为商店上架材料
- **时间**:以平台审核为准(通常 1~2 周)
- **费用**:免费
- **坑**:报告主体名/服务名必须与开发者主体、App 名一致;与 4.4 公安备案同平台,可一并操作

| PIPIA(个人信息保护影响评估) | 处理敏感个人信息(位置/偏好)触发,报告留存 ≥3 年 | 上架前后皆可,建议上架前完成 |

## 6. 不确定项与二次确认清单(办事前必须逐一核实)

1. **等保**:是否被强制要求、定级几级、是否影响 ICP 证受理 → 咨询属地通管局/公安网安与代办
2. **华为对婚恋类软著口径冲突**(官方页"非必选" vs 论坛"三选一")→ 以提审后台实际要求为准
3. **各省 ICP 证细则**:社保连缴月数、是否要求等保材料 → 代办/省通管局确认
4. **3 人社保的实操方案**(代办渠道挂靠 / 亲友入职 / 招聘)与真实成本 → 向当地代办询价,数字进预算
5. **公司注册地选择**(影响社保口径/备案管局/代办价格) → 用户决策
6. **腾讯云 IM 消息前回调**:核查项目是否使用(用到则 2026-10-01 起 1000 元/月) → 代码核查
