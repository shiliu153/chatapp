# 上线执行流程表(方案 A 双轨并行)实施计划

> **For agentic workers:** 本计划是**商务 + 技术混合流程**,不适用常规代码执行流程:商务轨任务由用户线下办理(Claude 负责准备材料、起草文稿、核对要求),技术轨任务由 Claude 执行(动服务器/代码前先与用户确认)。进度以 checkbox 为准。

**Goal:** 3~4 个月完成免费版双端上架(安卓五大商店 + 中国区 App Store);第 5~7 个月 ICP 证到手并开启付费;全程不碰"未持证收费"法律红线。

**Architecture:** 商务资质轨(主体→备案→商店)与技术上线轨(域名/HTTPS→短信/内容安全→提审)并行;四阶段 S0~S3;时间锚点 **T0 = 公司注册启动日**,周次均相对 T0。

**Tech Stack:** 既有栈(Django 5.2 + Flutter + 宝塔 + 阿里云轻量 + 腾讯云 IM/短信 + 天御内容安全)。

**关联文档:** 设计 spec `docs/superpowers/specs/2026-09-18-launch-compliance-budget-design.md`(预算表/资质五要素/来源链接全在其中);运维 `docs/deploy-runbook.md`。

## Global Constraints(全局约束,每个任务都适用)

- 🔴 **未持 ICP 证前,严禁开启任何付费功能**(会员/增值/打赏)。未持证收费罚 10 万~100 万或违法所得 3~5 倍,无过渡方案。
- 🔴 **App 名称一字不差原则**:软著名称 = App 备案名 = 各商店上架名,先定名(T-01)再启动一切;中途改名全部重来。
- 🔴 **备案期间域名不得开放网站访问**;ICP 备案通过后才能切域名、开 HTTPS、部署网页。
- 手机号 + 短信验证码已满足"后台实名"(法规认可),**不新增身份证号/人脸采集**,控制合规面。
- 腾讯云 IM 专业版(1499 元/月)**上架前必须采购**(体验版上限 100 用户);设置自动续费(到期直接停服)。
- 秘密值(短信密钥、支付密钥、备案账号口令)只进服务器 `chatapp/.env`(600)或用户本人保管,永不入 git。
- 纪律:凡改代码 → 后端 `python manage.py test` 全绿(前置 Redis)+ `flutter analyze` 零告警;每个技术任务完成即提交。
- 标注:**【用户操作】** = 你亲自办(我提供材料清单/话术/核对单);**【Claude 执行】** = 我操作(动服务器/代码前先确认)。
- 预算口径以 spec §3 为准;涉及花钱项先与用户确认档位再下单。

## 阶段总览

| 阶段 | 周次(相对 T0) | 商务资质轨 | 技术上线轨 | 阶段出口标准 |
|---|---|---|---|---|
| **S0 启动周** | W1~2 | 公司注册、社保起缴、软著申请 | 域名选型、服务器备案条件核查 | 执照到手 + 社保在缴 + 软著受理 |
| **S1 备案链** | W2~6 | ICP 备案 → 公安备案 / 安全评估 / App 备案;短信签名 | 域名 + HTTPS 切换、安全加固、隐私政策页 | ICP 备案号到手 + App 备案提交 |
| **S2 商店期** | W6~12 | 商店账号、材料打包、提审;IM 采购;支付商户 | 短信/内容安全接真、备份、注销入口、PIPIA | **免费版全渠道上架** |
| **S3 付费期** | W13~20+ | ICP 证、算法备案、等保(待定) | 支付功能开发(另立项)→ 开付费 | **ICP 证到手,付费版上线** |

## S0 启动周(W1~2)

### T-01 定名与主体决策【用户操作】(前置一切)

- [ ] 定 **App 名称**(2~4 个备选,查商店/商标是否冲突):此名将贯穿软著/备案/商店,一旦启动不可改
- [ ] 定 **公司注册城市**(影响:备案管局、社保口径、代办价格;建议社保便宜 + 线上办理成熟的城市)
- [ ] 定 **公司名称**(备 3~5 个,核名用)与注册资本(**100 万认缴**,经营范围必须含:婚姻介绍服务、互联网服务、**第二类增值电信业务**、软件开发)
- [ ] 选定 **预算档位**(spec §3:经济/标准/无忧,推荐标准档)

**产出:** 一份决策备忘(App 名/公司名/城市/档位)。**验收:** 四项全部书面确定,后继任务才能启动。

### T-02 公司注册【用户操作】(Claude 提供材料清单)

- [ ] Claude 输出材料清单与经营范围原文(可直接抄给代办/工商)
- [ ] 核名 → 设立登记(线上一网通办或代办)→ 领取执照
- [ ] **核对执照**:经营范围含"第二类增值电信业务"与"婚姻介绍服务"(漏了要立刻变更,否则 ICP 证阶段返工)
- [ ] 执照扫描件存档(后续备案/商店/支付全程复用)

**产出:** 营业执照(统一社会信用代码)。**耗时:** 3~10 工作日。**验收:** 执照信息与 T-01 决策一致且经营范围齐全。

### T-03 刻章 + 对公户 + 税务报到【用户操作】

- [ ] 刻章(公章/财务章/法人章,部分地区政府赠首套)
- [ ] 银行对公开户(需预约,带执照 + 法人身份证;部分银行要上门核址)
- [ ] 税务报到 + 确定 **代理记账**(2.4~6 千/年;公司成立即须按期报税)

**产出:** 对公账户(后续支付商户/商店对公打款都要用)。**耗时:** +1~2 周。**验收:** 对公户可收付款。

### T-04 社保开户 + 3 人社保起缴【用户操作】(ICP 证硬时钟)

- [ ] 公司社保账户开立
- [ ] 落实 **3 名参保人员**(方案与成本见 spec §6-4:代办挂靠/亲友入职;须**连续**缴纳 1~3 个月,省际口径以当地为准)
- [ ] 记录起缴月份(ICP 证申报时间 = 起缴月 + 连缴要求月数)

**产出:** 社保缴纳记录(ICP 证申报用)。**验收:** 3 人当月实缴成功(次月可在社保系统查到记录)。

### T-05 域名选型与购买【Claude 协助】

- [ ] 选定域名(.com 优先,与 App 名相关;查有无历史黑名单记录)
- [ ] **以公司名义**注册并进行实名认证(个人持有会导致备案主体不一致)
- [ ] 域名解析暂不开启(备案期间不得开放访问)

**产出:** 已实名域名 + 域名证书。**验收:** 域名持有者 = 公司主体名称。

### T-06 软著申请【用户提交,Claude 起草材料】

- [ ] Claude 生成:源码前后各 30 页(共 60 页,格式按版权中心要求)+ 软件说明书 + 申请表字段内容
- [ ] 用户在中国版权保护中心线上提交(主体 = 公司;**软著名称 = App 名**)
- [ ] 跟踪受理 → 下证(普通 30~60 工作日;赶时间可加急 3~10 工作日,费用见 spec §3.2)

**产出:** 软著登记证书。**验收:** 证书名称与 App 名一字不差。

### T-07 备案前置条件核查【用户操作,Claude 给核对单】

- [ ] 阿里云控制台确认轻量实例**剩余时长 ≥3 个月**(不足先续费;备案硬性要求)
- [ ] 申请 **阿里云备案服务码**(轻量实例每台可申请数量有限,确认够用)
- [ ] 确认服务器已用完好的主体资料(执照号/法人身份证信息)待录

**产出:** 备案条件核查单。**验收:** 服务码在手 + 时长满足。

## S1 备案链(W2~6)

### T-08 ICP 备案提交【用户操作主,Claude 协】

- [ ] 阿里云备案系统填写:主体(公司)、域名、服务器(备案服务码)
- [ ] 上传:营业执照、法人身份证、域名证书、核验单
- [ ] 法人**人脸核验** + 管局短信核验(注意 24 小时内完成)
- [ ] 跟踪:服务商初审(1~2 天)→ 管局审核(2~4 周);被驳回按 spec §4.2 常见原因排查

**产出:** **ICP 备案号**(挂在域名上)。**验收:** 工信部备案系统可查。**这一步是全链路的咽喉,驳回会卡住后面所有事。**

### T-09 域名 + HTTPS 切换与安全加固【Claude 执行】(前置:T-08 通过)

- [ ] 域名解析到服务器;宝塔站点绑定域名 + 申请 Let's Encrypt 证书(自动续签)
- [ ] 全站切 HTTPS(HTTP 301 → HTTPS);复查 `CSRF_TRUSTED_ORIGINS` / `ALLOWED_HOSTS`
- [ ] **同步改 `MEDIA_BASE_URL` 为 https 域名,重刷腾讯 IM 用户头像**(runbook 有步骤,漏了头像会挂)
- [ ] 安全加固:宝塔面板 <PANEL_PORT> 白名单/改强口令、**关闭 SSH 密码登录**、HSTS、firewalld 与阿里云控制台端口复核
- [ ] 重建 APK(新 `API_BASE=https://域名/api/v1`)装模拟器全链路回归:登录→滑卡→配对→聊天→广场→presence

**产出:** `https://域名` 全站可用。**验收:** HTTPS 全绿 + 双模拟器核心链路手测通过(按你的惯例:你亲自在模拟器上跑一遍)。

### T-10 隐私政策 + 用户协议网页部署【Claude 起草+部署】(前置:T-09)

- [ ] Claude 起草隐私政策(含:收集种类/目的/保存期限/**第三方 SDK 清单**/单独同意入口/撤回与注销路径)与用户协议
- [ ] 部署为独立可公开访问 URL(`https://域名/privacy`、`/terms`)
- [ ] App 内协议弹窗与网页版本内容核对一致(商店审核会比对)

**产出:** 可公开访问的隐私政策 URL(商店与 App 备案的必交材料)。**验收:** 未登录状态浏览器可打开。

### T-11 公安联网备案【用户操作】(前置:T-08 通过,30 日内)

- [ ] beian.mps.gov.cn 提交:执照、法人身份证、ICP 备案号、域名证书
- [ ] 审核通过后留存备案号(商店材料用)

**产出:** 公安联网备案号。**耗时:** 3~5 天。

### T-12 安全评估报告【用户提交,Claude 起草】

- [ ] Claude 起草自评估报告(主体信息/服务内容/安全管理制度/技术措施/个人信息保护)
- [ ] 全国互联网安全管理服务平台提交 → 取得"通过"结果
- [ ] 截图存档(华为/小米/vivo 上架必交;报告主体名 = 公司、服务名 = App 名)

**产出:** 安全评估"通过"截图。**费用:** 免费自评。

### T-13 App 备案提交【用户操作主,Claude 协】(前置:T-08 + T-10 必达)

- [ ] 通过接入商(阿里云/腾讯云)提交:**包名、签名公钥与 MD5**(从 keystore 提取,Claude 提供命令)、隐私政策 URL、SDK 清单、图标
- [ ] 跟踪管局审核(1~3 周,法定 20 工作日);驳回常见原因:主体/域名不一致、SDK 清单与实际不符、签名不匹配

**产出:** **App 备案号**(-A,安卓与 iOS 同名只备一次)。**验收:** 工信部系统可查。

### T-14 短信签名与模板申请【用户操作,Claude 备文稿】

- [ ] 腾讯云短信:申请签名(公司名/App 名)+ 验证码模板;需企业资质(+ 可能需 App 备案/上架信息,以后台要求为准)
- [ ] 提交后跟踪审核 + 运营商报备(5~10 工作日)
- [ ] 通过后通知 Claude 做 T-15 接真

**产出:** 签名与模板审核通过。**注意:** 若后台要求提供已上架证明,则顺延至 S2。

## S3 付费开通(W13~20+)

### T-25 ICP 经营许可证申报【用户操作,Claude 起草材料】(前置:T-04 社保连缴满)

- [ ] Claude 起草:业务发展方案 + 技术方案(申报材料中工作量最大部分)
- [ ] 用户确认社保连缴月数满足属地要求 → 省通信管理局线上申报
- [ ] 跟踪:受理 → 审查 → 发证(40~60 工作日);被要求补等保材料的按 T-27 处理

## 风险与回退

| 风险 | 回退 |
|---|---|
| 个别商店坚持要 ICP 证才收免费版 | 该店延后到 T-25 取证后重提;先上其余商店 |
| ICP 备案被驳回 | 按 spec §4.2/4.3 驳回原因清单逐项排查重提(主体一致性是第一大坑) |
| 社保人数/月数不够 | 与代办确认挂靠方案或补齐人数,ICP 证申报顺延(付费期整体后移) |
| iOS 无 Mac 环境 | 云构建服务过渡;或 iOS 延后(iOS 收入本就受 IAP 佣金侵蚀) |
| 活动价/政策变动 | spec §6 不确定项清单,办事前逐项二次确认 |
| 内容安全/支付开发量超预期 | 各自另立项 spec,不影响免费版上架主链路 |
