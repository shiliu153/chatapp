# 批次 M–Q 实施计划(工单拆解)

- **Spec**:[2026-11-09-batch-m-q-design.md](../specs/2026-11-09-batch-m-q-design.md)
- **Goal**:交付 5 个功能(登录设备 / 会话管理三件套 / 滑卡增强 / 使用报告 / 聊天敏感词),
  每批按栈拆单、单独自证、合并进 `master`;不发版(版本号 / tag / Release / 部署留给主人)。
- **Architecture**:M/P/O 走 Django(`accounts` / `stats` 新模块 / `discovery`),
  N/Q 走 imserver(C++20 + 新迁移 + 新客户端 HTTP 接口),App(Flutter)与 Web(Vue 3)各自跟一单。
- **Global Constraints**:
  1. 一 PR 一条栈;契约联动(openapi / `docs/api/*.md` / `web/src/api/schema.d.ts` / WS fixture)同 PR 做完。
  2. 推之前跑 `scripts/verify.sh <该栈>` 并贴末尾输出。
  3. App UI 改动必须在 `emulator-5554` 手测并截图。
  4. 不发版:不升版本号、不打 tag、不建 Release、不部署生产。
  5. 每批合并后 Windows 仓库 `git pull --ff-only`。

### 与计划的偏差

1. **执行方式**:原计划交 WSL superagent worker,实际**worker 起初连不上 GitHub**(见 spec §1.1),开工时按 Windows 内联准备;代理拉起并修掉 `no_proxy` 里错误排除 `api.github.com` 之后,worker 恢复,**最终 15 个 PR 全部由 worker 实现**,Windows 侧只做设计、评审、合并与模拟器验收。`scripts/verify.sh bootstrap`、`/root/node22` 也在本轮补齐。
2. **多出一张单(T1 补 / #189)**:模拟器验收发现「踢掉某端后它仍留在登录设备列表里」—— 原设计只写了「版本 +1」,没写「下线 = 从列表消失」。补 `DeviceSession.logged_out_at` 后闭环。
3. **业务码从 `40001` 改成 `40003`/`40004`/`40005`**:三个后端单并行时都按工单口径用 `40001`,评审时发现 `40001` 全局语义是「验证码过期」,统一改成一码一义(`40003` 无可撤销滑卡 / `40004` 端类型非法 / `40005` period 非法)。
4. **周口径**:工单里给的示例 `2026-11-03 ~ 2026-11-09` 是滚动 7 天,与「自然周(周一起)」自相矛盾;以文字规则为准(worker 判断正确),示例已作废。
5. **`verify.sh imserver` 顺手补齐**:Q 批发现该子命令只跑集成,漏了 unit 与 db 两段(与 `imserver.yml` 的三个 step 不对齐),同单补齐。

### 踩到的坑

1. **宿主 TUN 代理 + WSL NAT**:WSL 出网绕不过 Windows 的 VPN,且 `no_proxy` 里排除了 `api.github.com`(该域名在 WSL 内被解析到 `127.0.0.1`),表现是 worker 一直 `github: error`、ticket 的 prepare 报 `gnutls_handshake`。修法:去掉 `no_proxy` 里的 `api.github.com` 并重启 worker。
2. **`scripts/verify.sh` 是 WSL 专用工具**:web/app 拒绝非 Linux 文件系统、venv 默认 `$HOME`,在 Windows 的 Git Bash 里跑不通 —— 所以验证一律在 WSL 的 `/root/src/chatapp` 里跑,契约门禁(版本号/App 模型)可以单独用 Windows 的 conda python 等价执行。
3. **worker 并发会互相拆测试库**:多个 worker 同时跑 `verify.sh backend` 会共用 `test_chatapp_dev`,表现为 `Unknown column` / `Lost connection`(不是代码问题);worker 自己改用独立端口(38306/36379)的同镜像实例绕开了。
4. **Worktree 里构建 App 缺 `key.properties`**:`git worktree` 出来的目录没有 gitignored 的 `app/android/key.properties` 与 `local.properties`,Gradle 直接报 `null cannot be cast to non-null type kotlin.String`;从主仓库拷过去即可。**2026-11-12 更新(#253)**:缺 `key.properties` 时已回落 **debug 签名**,debug 构建/CI 不再需要拷;要产出**发布签名**包仍需拷(或有 `key.properties` 的主仓库)。
5. **本地跑通聊天链路需要 imserver 三件事**:`chatapp_im` 库 + `--migrate`(迁移**不会**在启动时自动跑,要显式 `imserver --migrate`)+ `IM_INTERNAL_ALLOW` 放行 Docker 网关网段(否则 Django 调 `/internal/pair` 403)。
