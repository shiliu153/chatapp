## 一、这套文档怎么用

1. 打开总纲确认下一批是哪个编号，然后打开本目录对应的那一册。
2. 每册固定六节，**按顺序走**：

   | 节 | 作用 | 能不能跳 |
   |---|---|---|
   | §1 本批目标 | 学完你能回答什么问题 | 不能跳，先知道要去哪 |
   | §2 读前必建概念 | 读代码前需要有的框架认知（不讲会看不懂） | **绝对不能跳** |
   | §3 精读清单 | 文件 + 精确行号 + 每段在干什么 | 主干 |
   | §4 动手实验 | 可复制命令 + 预期输出 + 观察点 | **不能跳**，跳了就变"以为看懂了" |
   | §5 自查题 | 含参考答案，先自己答再看 | 验收用 |
   | §6 卡住时查哪里 | 出问题去哪一册踩坑文档 | 备用 |

3. 每批结束，写一份笔记（模板见总纲第 5 节），勾掉总纲里的 checkbox，并在本文件底部进度表更新一行。

## 二、三条铁律（重述，因为它是成败关键）

1. **只查当前这一个概念**：读到 `select_related` 不认识，就只查它，查完立刻回到原文件。顺着 Django 官方文档跳走是通读失败的头号原因。
2. **每批必须改一行代码**：§4 的实验是"看懂"与"以为看懂"的分界。
3. **不懂就记账**：当场没懂的写进笔记「存疑清单」，攒到 P14 集中清空，不要在一处卡死。

## 三、命令约定

- 所有 `python manage.py ...` 命令的 **cwd 都是 `chatapp/`**（`manage.py` 所在层）。
- Python 解释器用 anaconda 环境 `Django`（实测 Python 3.10.19 + Django 5.2.9）：
  ```powershell
  conda activate Django
  ```
- **控制台中文乱码**时，命令前加两行环境变量：
  ```powershell
  $env:PYTHONIOENCODING = 'utf-8'; $env:PYTHONUTF8 = '1'
  ```
- **后端测试永远串行**（两个测试进程会抢同一个测试库），脚本/CI 一律加 `--noinput`。理由与现场见 [P00](P00-环境与反馈回路.md) 与 [../../pitfalls/testing.md](../../pitfalls/testing.md)。
