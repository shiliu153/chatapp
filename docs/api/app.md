# 应用配置

本分册含 1 个接口:客户端启动时读取最低版本要求。接口公开,不需要鉴权。

---

### 1.1 获取应用配置

> `GET` `/api/v1/app/config` · 不需要鉴权 · 无额外限流

**接口描述**

App 启动时(登录页之前)调用;`min_app_version` 高于本地版本时显示阻塞页并引导下载,不允许进入主界面。

**请求参数**

无。

**响应参数**

| 参数名称 | 类型 | 描述 |
|----------|------|------|
| min_app_version | String | 最低可用版本,低于此版本必须升级 |
| latest_version | String | 最新版本号(展示用) |
| download_url | String | 安装包下载地址;为空时不展示下载按钮 |

**请求示例**

```bash
curl http://<域名>/api/v1/app/config
```

**响应示例**

```json
{
  "min_app_version": "1.0.0",
  "latest_version": "1.0.0",
  "download_url": ""
}
```

**错误码**

| 错误码 | HTTP | 描述 | 处理建议 |
|--------|------|------|----------|
| 500 | 500 | 服务端内部错误 | 稍后重试;失败不阻断启动 |
