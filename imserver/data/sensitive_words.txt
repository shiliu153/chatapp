# imserver 聊天文字敏感词表(批次 Q,2026-11-09)
#
# 格式:UTF-8,一行一词;`#` 开头为注释,空行忽略;大小写不敏感(只对 ASCII 生效)。
# 命中 = 拒发:上行 send 的 kind=text 命中任一词 → 42201「消息包含违规内容」,
#         不落库、不推送、不计未读(只拦客户端上行文本;图片/语音/贴纸/系统灰条不查)。
#
# ★ 示例词表,主人按需增删。
#   - 想加词:直接加一行,重启容器生效(本文件随镜像打包,见 Dockerfile)。
#   - 想关掉整个功能:把本文件清空(只留注释也算空),或让 IM_SENSITIVE_WORDS_FILE 指向一个空文件。
#   - 改法、指标与排障见 docs/ops/imserver.md「聊天文字敏感词」。
#
# 维护提醒:这里只放**明确违规**的词(暴力 / 毒品 / 诈骗 / 引流)。越短越常见的词越容易误伤
# (例如单独一个「贷款」「兼职」会打到正常聊天),宁可写长一点(「无抵押贷款秒下」而不是「贷款」)。
